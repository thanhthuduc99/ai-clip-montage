# Font

`BeVietnamPro-Bold-full.ttf` là Be Vietnam Pro (Bold) của Bùi Đình Khoa,
phát hành theo SIL Open Font License 1.1.

- Nguồn: https://fonts.google.com/specimen/Be+Vietnam+Pro
- License: https://openfontlicense.org

File này dùng để vẽ hook và phụ đề lên video. Muốn đổi font khác thì thay
đường dẫn `CAPTION_FONT` trong `tools/subtitles.py`.
